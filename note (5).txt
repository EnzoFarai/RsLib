2. Use `npm pack @supabase/supabase-js@<version>` (npm verifies the tarball against the registry's published `integrity` field, which is SHA-512 signed by npm).

4. Compute and record the SHA-256 of the resulting `.js` file in the script itself, so subsequent re-runs abort if the upstream bundle differs.

- `getAnnotationLink(course, lesson)` — SELECT `token, revoked_at`.
- `ensureAnnotationLink(course, lesson)` — INSERT … ON CONFLICT DO NOTHING.
- `revokeAnnotationLink(course, lesson)` — RPC `revoke_annotation_link`.
- `reshareAnnotationLink(course, lesson)` — RPC `reshare_annotation_link`.
- `annotationLink(course, lesson, token)` — builds `/read/{c}/{l}.html?view={token}`.
- `sharedLesson(token)` — RPC `get_shared_reading_lesson`; returns `{status:'ok'|'revoked', data?}` or `null`.
- `getCollectionByUsername(username, kind)` — RPC `get_collection_by_username`; returns `{status:'ok'|'denied', data?}`.
- `shareCollection(kind)` — RPC `share_collection`.
- `customOrder(kind)` — reads `reading_bookmarks.sort_index` or `reading_collection_order`.
- `saveOrder(kind, entries)` — bulk UPDATE.
- `copyText(text)` — navigator.clipboard + execCommand fallback.
- `shareText(title, url, passage)` — navigator.share; returns `'shared' | 'cancelled' | 'fallback'`.

Handling of `?view=`: a helper `viewTokenFromUrl()` returns the parsed token or null. The `sharedLesson` RPC is only called by the annotation module.

### 6.2 `src/js/reading-annotations.js`

Module-level flow:

1. `lessonFromPath()` → if null, abort.
2. Fetch `#articleContent` → if null, abort.
3. Read `?view=` from `URL`.
4. Try `owner()`:
   - **Logged in:**
     - If `?view=` present and equals the owner's own token → treat as own view.
     - If `?view=` present and different → `sharedLesson(token)`:
       - `{status:'revoked'}` → render banner "This annotated view has been revoked. Continue reading without annotations."
       - `{status:'ok', data}` with `course_id/lesson_id` mismatch → clear URL param, reload clean.
       - `{status:'ok', data}` matching → render read-only annotations, set `readonly = true`.
       - `null` (invalid or zero annotations) → clear URL param, reload clean.
     - If no `?view=` → own view: fetch `myAnnotations(course, lesson)`.
     - Sync URL: if own view and annotations exist, `history.replaceState` to `?view=<token>`; if zero annotations, strip any `?view=`.
   - **Anonymous:**
     - If `?view=` present → `sharedLesson(token)` (RPC is granted to `anon`), apply above rules.
     - If no `?view=` → render clean article, annotation toolbar hidden.
5. Attach toolbar (`Highlight | Note | Copy | Share`), colour picker (six colours, MRU persisted to `localStorage('vr_recent_color')`).
6. Wire selection change handler.
7. Attach note folder UI.
8. Bookmark button: reflect `myBookmarks()` state; click calls `setBookmark`.

Key behaviours implemented:

- **Text selection offset computation:** `selectionOffsets()` walks `articleContent` text nodes to produce absolute character offsets, then uses `Range` cloning to preserve cross-inline selection.
- **Word-boundary expansion:** `expandRangeToWordBoundaries()` extends start/end to nearest non-word character, bounded by paragraph edges, so partial words never produce broken highlights.
- **Rendering:** uses CSS Custom Highlight API (`::highlight(vr-bee)` etc. defined in `reading-annotations.css`) so overlapping highlights and notes coexist without DOM mutation.
- **Asterisk insertion:** for each note row, inserts a single `<i class="ph ph-asterisk vr-note-asterisk">` before the first character of the note, right-to-left to preserve offsets.
- **Colour swap:** clicking inside an existing highlight of a different colour opens the colour picker; picking a colour performs `updateAnnotation` on the existing highlight's `color` field and re-renders, preserving the row `id` and offsets.
- **Note editor:** folder-style UI matching the reference; save/edit/delete flows call `putAnnotation` / `updateAnnotation` / `deleteAnnotation` and re-fetch.
- **Four sharing flows:**
  1. **Selected text** — `shareText(title, window.location.href, quote)`; if `'fallback'`, shows the share menu with WhatsApp / Telegram / Email / Copy excerpt.
  2. **Lesson** — `shareText(document.title, lessonURL(course, lesson))`; no token.
  3. **Annotated view** — only if owned and rows.length > 0: `shareText(title, annotationLink(course, lesson, token))`.
  4. **Collection** — the annotation module does not initiate this; the collection manager handles it.
- **Revoked-state handling** as above.
- **`{status:'revoked'}` propagation** to a persistent banner; article rendered without annotations.
- **`?view=` mismatch with owner's own token** → treat as foreign share, not as own.

Runtime caveat: `::highlight()` rendering requires browser support (Chrome 105+, Safari 17.2+, Firefox 140+). If unsupported, a toast informs the user; notes still saved.

### 6.3 `src/js/reading-collections.js`

```bash
#!/usr/bin/env bash
# src/lib/vendor-supabase.sh
#
# Vendors @supabase/supabase-js@PINNED_VERSION as a fully bundled,
# browser-compatible ESM file at src/lib/supabase.min.js.
#
# The resulting file has all internal dependencies (auth-js, postgrest-js,
# realtime-js, storage-js, functions-js) inlined. No package.json, no
# Vite/bundler, and no runtime CDN reference are required.
#
# Usage:
#     bash src/lib/vendor-supabase.sh
#
# Idempotency:
#     On the first successful run, the bundle's SHA-256 is written to
#     src/lib/SUPABASE_BUNDLE_SHA256.txt. Subsequent runs verify the
#     local bundle against that recorded hash; if they match, the script
#     exits without re-downloading. If they do not match, the script
#     warns and re-downloads (this catches accidental local edits and
#     upstream tampering of the pinned version).
#
#     To upgrade to a new pinned version, edit PINNED_VERSION below,
#     delete src/lib/SUPABASE_BUNDLE_SHA256.txt, and re-run.
#
# Requirements: bash, curl, sha256sum.

set -euo pipefail

PINNED_VERSION="2.45.4"
BUNDLE_URL="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@${PINNED_VERSION}/+esm"
LICENSE_URL="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@${PINNED_VERSION}/LICENSE"

DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
BUNDLE="${DIR}/supabase.min.js"
LICENSE="${DIR}/SUPABASE_LICENSE.txt"
HASH_FILE="${DIR}/SUPABASE_BUNDLE_SHA256.txt"

command -v curl      >/dev/null 2>&1 || { echo "ERROR: curl is required.";      exit 1; }
command -v sha256sum >/dev/null 2>&1 || { echo "ERROR: sha256sum is required."; exit 1; }

# -------- Idempotency: skip if already vendored and hash matches --------
if [[ -f "${BUNDLE}" && -f "${HASH_FILE}" ]]; then
  RECORDED=$(tr -d '[:space:]' < "${HASH_FILE}")
  ACTUAL=$(sha256sum "${BUNDLE}" | awk '{print $1}')
  if [[ "${RECORDED}" == "${ACTUAL}" ]]; then
    echo "Already vendored at @supabase/supabase-js@${PINNED_VERSION} (SHA-256: ${ACTUAL})."
    exit 0
  fi
  echo "WARNING: existing bundle hash does not match the recorded value."
  echo "  Recorded: ${RECORDED}"
  echo "  Actual:   ${ACTUAL}"
  echo "Proceeding to re-download the pinned version..."
fi

TMP="$(mktemp)"
trap 'rm -f "${TMP}"' EXIT

# -------- Download the pre-bundled ESM --------
echo "Downloading @supabase/supabase-js@${PINNED_VERSION} (bundled ESM from jsDelivr)..."
curl -fsSL "${BUNDLE_URL}" -o "${TMP}"

SIZE=$(wc -c < "${TMP}")
if [[ "${SIZE}" -lt 100000 ]]; then
  echo "ERROR: downloaded file is unexpectedly small (${SIZE} bytes)."
  echo "       This is likely an error page rather than the bundle."
  echo "       First 200 bytes follow:"
  head -c 200 "${TMP}" || true
  echo ""
  exit 1
fi

if ! grep -q 'createClient' "${TMP}"; then
  echo "ERROR: downloaded file does not contain 'createClient'. Aborting."
  exit 1
fi

mv "${TMP}" "${BUNDLE}"
trap - EXIT

HASH=$(sha256sum "${BUNDLE}" | awk '{print $1}')
printf '%s\n' "${HASH}" > "${HASH_FILE}"

# -------- Licence --------
echo "Downloading licence..."
curl -fsSL "${LICENSE_URL}" -o "${LICENSE}"

echo ""
echo "Vendored @supabase/supabase-js@${PINNED_VERSION}."
echo "  ${BUNDLE}  (${SIZE} bytes)"
echo "  SHA-256: ${HASH}"
echo "  ${LICENSE}"
echo "  ${HASH_FILE}  (recorded for future idempotent runs)"
echo ""
echo "Next: change the import line in src/js/supabase.js to"
echo "  import { createClient } from '/src/lib/supabase.min.js';"
```

-- RPC 2: get_collection_by_username(p_username text, p_kind text)
-- Uniform {"status":"denied"} for every deny reason.
-- Honours sort_index from reading_bookmarks and
-- reading_collection_order.
-- ============================================================
CREATE FUNCTION public.get_collection_by_username(p_username text, p_kind text)
RETURNS jsonb
LANGUAGE plpgsql
STABLE
SECURITY DEFINER
SET search_path = ''
AS $$
DECLARE
  v_uid         uuid := auth.uid();
  v_owner       uuid;
  v_link        record;
  v_owner_name  text;
  v_items       jsonb;
  v_is_owner    boolean := false;
  v_shared      boolean := false;
  v_kind_ann    text;
BEGIN
  IF p_username IS NULL
     OR p_kind IS NULL
     OR p_kind NOT IN ('bookmarks','highlights','notes') THEN
    RETURN pg_catalog.jsonb_build_object('status', 'denied');
  END IF;

  SELECT id INTO v_owner FROM public.profiles WHERE username = p_username;
  IF NOT FOUND THEN
    RETURN pg_catalog.jsonb_build_object('status', 'denied');
  END IF;

  IF v_uid IS NOT NULL AND v_uid = v_owner THEN
    v_is_owner := true;
    SELECT visibility, revoked_at INTO v_link
      FROM public.reading_collection_links
     WHERE owner_id = v_owner AND kind = p_kind;
    v_shared := FOUND
                AND v_link.visibility = 'public'
                AND v_link.revoked_at IS NULL;
  ELSE
    SELECT visibility, revoked_at INTO v_link
      FROM public.reading_collection_links
     WHERE owner_id = v_owner AND kind = p_kind;
    IF NOT FOUND
       OR v_link.visibility <> 'public'
       OR v_link.revoked_at IS NOT NULL THEN
      RETURN pg_catalog.jsonb_build_object('status', 'denied');
    END IF;
    v_shared := true;
  END IF;

  SELECT coalesce(
           nullif(p.display_name, ''),
           nullif(p.username, ''),
           'Vulanet reader'
         )
    INTO v_owner_name
    FROM public.profiles p
   WHERE p.id = v_owner;

  IF p_kind = 'bookmarks' THEN
    SELECT coalesce(
             pg_catalog.jsonb_agg(
               pg_catalog.jsonb_build_object(
                 'course_id',  b.course_id,
                 'lesson_id',  b.lesson_id,
                 'updated_at', b.updated_at
               ) ORDER BY b.sort_index ASC NULLS LAST, b.created_at DESC
             ),
             '[]'::jsonb
           )
      INTO v_items
      FROM public.reading_bookmarks b
     WHERE b.owner_id = v_owner;
  ELSE
    v_kind_ann := CASE WHEN p_kind = 'notes' THEN 'note' ELSE 'highlight' END;
    SELECT coalesce(
             pg_catalog.jsonb_agg(
               pg_catalog.jsonb_build_object(
                 'course_id',  x.course_id,
                 'lesson_id',  x.lesson_id,
                 'updated_at', x.updated_at
               ) ORDER BY co.sort_index ASC NULLS LAST, x.updated_at DESC
             ),
             '[]'::jsonb
           )
      INTO v_items
      FROM (
        SELECT a.course_id, a.lesson_id,
               pg_catalog.max(a.updated_at) AS updated_at
          FROM public.reading_annotations a
         WHERE a.owner_id = v_owner
           AND a.kind     = v_kind_ann
         GROUP BY a.course_id, a.lesson_id
      ) x
      LEFT JOIN public.reading_collection_order co
        ON co.owner_id  = v_owner
       AND co.kind      = p_kind
       AND co.course_id = x.course_id
       AND co.lesson_id = x.lesson_id;
  END IF;

  RETURN pg_catalog.jsonb_build_object(
    'status', 'ok',
    'data',   pg_catalog.jsonb_build_object(
      'kind',       p_kind,
      'owner_name', v_owner_name,
      'is_owner',   v_is_owner,
      'shared',     v_shared,
      'items',      v_items
    )
  );
END;
$$;

GRANT EXECUTE ON FUNCTION public.get_collection_by_username(text, text) TO authenticated;

## Diagnosis

The reset failed because it dropped functions **before** tables. That ordering was wrong.

`_random_token()` is the `DEFAULT` expression on `reading_annotation_links.token`. PostgreSQL treats column defaults as hard dependencies on the function — you cannot `DROP FUNCTION _random_token()` while a table column's default uses it. The error is exactly correct:

> `cannot drop function _random_token() because other objects depend on it` — `default value for column token of table reading_annotation_links depends on function _random_token()`

**Nothing was dropped.** The `BEGIN;` / `COMMIT;` wrapper means the whole reset aborted atomically. Your database is still in the pre-existing state.

The fix is to reverse the order: **drop tables first** (which releases the column-default dependency and the trigger `tgfoid` bindings), then drop functions.
